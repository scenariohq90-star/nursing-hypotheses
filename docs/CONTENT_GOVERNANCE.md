# حوكمة المحتوى السريري | Clinical Content Governance

**النطاق:** جميع السيناريوهات والأسئلة والخيارات والتفسيرات والترجمات والدرجات والمراجع في «فرضيات تمريضية»  
**تاريخ قائمة المراجع:** تم التحقق من الصفحات الرسمية حتى 2026-09-04  
**مالك السياسة المقترح:** مجلس المحتوى السريري (Clinical Content Board)

**لقطة التنفيذ الحالية:** موقع ويب مستجيب يحتوي 12 سيناريوهاً خيالياً، و24 تنويع سياق، و39 قراراً، و117 خياراً، و46 سؤالاً تدريبياً أصلياً ثنائي اللغة موزعة على ثلاثة مسارات تمريضية مستقلة، و28 مصدراً ظاهراً. تحليلات التعلم وجلسة الاختبار المؤقتة محلية داخل المتصفح. لا توجد مصادقة أو قاعدة بيانات أو مدفوعات أو استحقاقات خادمية أو تكامل n8n فعلي في هذه النسخة. كل المحتوى الحالي `draft` وبانتظار مراجعة سريرية وقانونية ولغوية بشرية موثقة.

## 1. القاعدة الحاكمة

لا ينشر الموقع «الإجابة الصحيحة» لأن نموذجاً لغوياً أو محرراً واحداً اقترحها. كل حالة تعليمية يجب أن تكون خيالية، أصلية، محددة الجمهور والنطاق، مرتبطة بدليل قابل للتتبع، ومجازة سريرياً ولغوياً قبل النشر.

المحتوى تعليمي وليس رعاية صحية. الأنظمة السعودية الحالية، نطاق الممارسة، سياسة المنشأة، الأوامر المعتمدة، حالة المريض، وتقدير الفريق المسؤول تتقدم دائماً على أي مثال في الموقع.

## 2. التحذير الإلزامي

يظهر التحذير قبل أول حالة، داخل شاشة الحالة، وفي صفحة «حول»، من دون إخفائه داخل الشروط:

> **للتعلم والمحاكاة فقط. ليس لرعاية مريض حقيقي أو للتشخيص أو العلاج أو الفرز أو استخدام الطوارئ. لا تدخل أي معلومات لمريض حقيقي. اتبع سياسة المنشأة الحالية والأوامر المعتمدة ونطاق الممارسة ومسارات التصعيد. إذا كانت هذه حالة طارئة حقيقية، تواصل فوراً مع فريقك السريري وخدمة الطوارئ المحلية.**

> **Educational simulation only. Not for real patient care, diagnosis, treatment, triage, or emergency use. Do not enter real patient information. Follow current local policy, authorised orders, scope of practice, and escalation pathways. If this is a real emergency, immediately contact your clinical team and local emergency service.**

تظهر بجوار الدرجة عبارة واضحة: «تغذية راجعة تعليمية، وليست تقييماً للكفاءة المهنية» / “Learning feedback, not a professional competency assessment.”

## 3. مجلس المراجعة السريري

### التكوين الأدنى

| الدور | المسؤولية |
| --- | --- |
| رئيس المجلس: ممرض/ـة مثقف/ـة سريري/ـة أقدم | يملك العملية ويحل التعارض الإجرائي ولا يتجاوز اعتراض سلامة موثقاً |
| قائد تمريضي للقسم المعني | يراجع الواقعية، الأولوية، نطاق الممارسة، والتصعيد |
| مراجع تمريضي مستقل | لا يكون مؤلف الحالة؛ يحاول إثبات أن الإجابة أو distractors غامضة أو خطرة |
| أخصائي محاكاة/تعليم تمريض | يراجع الأهداف، prebriefing، التدرج، debriefing، والقياس التكويني |
| مختص سلامة مرضى/جودة | يراجع الهوية والدواء والتواصل والتسليم والعوامل النظامية وعدم ثقافة اللوم |
| صيدلي سريري | إلزامي لكل جرعة أو توقيت أو تداخل أو حساسية أو إعطاء دواء |
| مختص وقاية من العدوى | إلزامي لمحتوى العزل وPPE والتعقيم والتعرض |
| مختص فئة سكانية | أطفال/حديثو ولادة/أمومة/صحة نفسية/مسنون بحسب الحالة |
| أخصائي معلومات صحية | يوثق البحث والإصدار وDOI وحالة السحب والترخيص |
| مترجم طبي عربي | ينتج الترجمة البشرية من النص السريري المعتمد |
| مراجع تمريضي ثنائي اللغة مستقل | يتحقق من تكافؤ المعنى والمصطلح والخطر في العربية |
| قانوني/خصوصية/ترخيص | يراجع الاقتباس وإعادة الاستخدام والادعاءات والاحتفاظ |
| ممثل متعلم ووصول | يختبر الفهم والعبء المعرفي ولوحة المفاتيح وقارئ الشاشة |

### النصاب والقرار

- يتطلب نشر حالة موافقة قائد المجال، والمراجع التمريضي المستقل، وأخصائي المحاكاة، ومراجع العربية. يضاف الصيدلي أو مختص العدوى أو الفئة السكانية عند انطباق المجال.
- لا تنشر الحالة مع اعتراض سلامة عالي الخطورة غير محلول، حتى لو وافقت الأغلبية.
- يصرح كل عضو بتعارض المصالح والعلاقة بالناشر أو المزود. يمتنع صاحب التعارض المادي عن قرار الترخيص أو التفضيل.
- يسجل القرار: `approve` أو `approve-with-editorial-fixes` أو `return` أو `withdraw`، مع الأسماء والأدوار والتاريخ والنسخة والسبب.
- الذكاء الاصطناعي ووكلاء البرمجة أدوات مساعدة بلا صوت في المجلس ولا صلاحية اعتماد أو نشر.

## 4. التأليف الأصلي ومنع نسخ بنوك الأسئلة

### المسموح

- ابتكار شخصيات وأرقام وتسلسل زمني خيالي يخدم هدفاً محدداً.
- تلخيص أو إعادة صياغة مبدأ إرشادي بلغة أصلية مع إسناد واضح، بعد مراجعة شروط المصدر.
- ربط المستخدم بصفحة الناشر أو DOI بدلاً من إعادة توزيع العمل.
- ذكر مقدار قصير لازم للتعريف بالمفهوم عندما يسمح القانون والترخيص، مع توثيق مصدره ومراجعته القانونية عند الشك.
- استخدام مجالات تعلم تمريضية عامة وصيغة أفضل إجابة واحدة بوصفهما منهجاً تعليمياً عاماً، من دون نشر مخططات مالكي الاختبارات أو استخدام أسمائهم في تسمية المسارات العامة حتى اكتمال مراجعة الحقوق والعلامات.
- استخدام وصف عام مثل «تدريب تمريضي مستقل للاختبارات المحوسبة» ما دام تنبيه الاستقلال ظاهراً ولا يُستخدم اسم أو شعار مزود تقديم اختبار في اسم المنتج أو المسار أو النطاق أو التسويق.

### الممنوع

- نسخ أو إعادة ترتيب سؤال أو حالة أو distractors من اختبار، بنك أسئلة، دورة، كتاب، ENA/AHA أو أي منتج تدريبي مغلق.
- إعادة رسم خوارزمية أو جدول أو شكل محمي بتغيير الألوان فقط.
- ترجمة محتوى محمي كاملاً؛ الترجمة عمل مشتق وقد تتطلب إذناً مستقلاً.
- رفع كتاب أو PDF مدفوع أو بنك أسئلة إلى نموذج ذكاء اصطناعي إن لم تسمح الرخصة والعقد بذلك.
- استخدام قصة مريض حقيقي أو تواريخ/خصائص يمكن جمعها لإعادة التعرف، حتى بعد حذف الاسم.
- الادعاء أن المحتوى «معتمد من» جهة لم تمنح اعتماداً مكتوباً.
- وصف السؤال بأنه صادر عن اختبار أو جهة تنظيمية، أو الإيحاء بأن النتيجة تتنبأ بالنجاح أو الجاهزية للترخيص أو الكفاءة المهنية.
- تسمية البنك باسم مزود تقديم اختبار أو استخدام علامته أو شعاره أو وصفه بأنه «نماذج رسمية» من دون إذن مكتوب ومراجعة علامات موثقة.

يفتح لكل حالة سجل أصالة يذكر المؤلف، تاريخ التأليف، المصادر الاسترشادية، فحص التشابه، وأي إذن كتابي. الاشتباه في النسخ يوقف النشر حتى يحسمه مسؤول الترخيص.

البنك الحالي مؤلف من الصفر ويضم 15 سؤالاً لمسار الدراسة السعودي المستقل، و15 لمسار دراسة الممرض المسجل الدولي المستقل، و16 لمسار التدريب المحوسب المستقل. يحمل كل سؤال `official: false` و`fictional: true` و`reviewStatus: draft`، ويستشهد بالمصادر السريرية فقط في الواجهة. تظهر عبارة واضحة بأن المنصة لا تصدر عن أي جهة تنظيمية أو مالك اختبار أو مزود تقديم اختبارات ولا ترعاها أو تؤيدها أو تعتمدها أو تديرها أيٌّ منها.

## 5. دورة إعداد الحالة

1. **تحديد الفجوة:** جمهور محدد، قسم، مستوى، هدف تعلم قابل للملاحظة، وخطر يريد التدريب عليه.
2. **صياغة سؤال الدليل:** PICO أو إطار مناسب، مع سياق السعودية ونطاق الممارسة.
3. **بحث موثق:** بروتوكول محلي حالي، مصادر وطنية، إرشادات تخصصية، مراجعات منهجية، ثم دراسات أولية عند الحاجة.
4. **استخراج الدليل:** النسخة/السنة، رقم التوصية أو الموضع، قوة التوصية ويقين الدليل، المجتمع، الاستثناءات، وتاريخ الوصول.
5. **حل التعارض:** يوثق سبب اختيار مصدر أو تقييد قابلية التطبيق؛ لا تدمج التوصيات المتعارضة في جملة واثقة.
6. **Blueprint الحالة:** الأهداف، نقطة البداية، المعلومات التي تنكشف، القرارات، الأخطار، نهاية التعلم، وdebriefing.
7. **تأليف إنجليزي أصلي:** بلا نص أو بنية مستنسخة من بنك أسئلة.
8. **مراجعة سريرية عمياء قدر الإمكان:** يتحدى المراجع جميع الخيارات ويبحث عن أكثر من إجابة مقبولة.
9. **تقييم السلامة والدرجات:** يطابق التصنيف مع الدرجة؛ لا يعوض المتوسط قراراً غير آمن.
10. **ترجمة عربية بشرية ثم مراجعة مستقلة:** بعد تجميد النسخة الإنجليزية السريرية.
11. **تحقق وظيفي ووصول:** الجوال `390px`، RTL/LTR، لوحة المفاتيح، قارئ الشاشة، الروابط، والوحدات.
12. **قرار المجلس والنشر:** إصدار ثابت، تاريخ نشر ومراجعة تالية، سجل تغييرات، ومالك.
13. **مراقبة ما بعد النشر:** بلاغات، أداء البنود، تغير المصادر، والانحراف بين اللغتين.

## 6. تقييم الدليل وقابلية التطبيق

### ترتيب المصادر

1. الأنظمة ونطاق الممارسة والبروتوكول المؤسسي السعودي الحالي للموقع المستهدف.
2. وزارة الصحة السعودية، الهيئة السعودية للتخصصات الصحية، والمركز السعودي لسلامة المرضى.
3. إرشادات دولية حديثة من الجهة العلمية المالكة، مع بيان قوة التوصية ويقين الدليل.
4. مراجعات منهجية عالية الجودة وتقييمات تقنية صحية.
5. دراسات أولية محكمة ومصادر تعليمية تفسيرية عند غياب الأعلى.

صفحة بحث أو ملخص مولد أو إجابة AI ليست مصدراً. هي وسيلة اكتشاف فقط؛ يجب فتح الوثيقة الأصلية وتقييمها.

### ما يسجل لكل claim

- `referenceId`، العنوان، الجهة، السنة/الإصدار، URL/DOI، وتاريخ الوصول.
- التوصية/الصفحة أو القسم المستخدم داخلياً، ونوع الدليل.
- قوة التوصية ويقينها كما نشرهما المصدر؛ لا تحول “conditional” أو “insufficient evidence” إلى أمر قاطع.
- المجتمع والبيئة والاستثناءات ومدى انطباقها على الدور التمريضي السعودي.
- ما إذا كان الإجراء مستقلاً تمريضياً أو يتطلب أمراً/بروتوكولاً/فريقاً.
- اسم المستخرج والمراجع وقرار المجلس.

## 7. الترجمة العربية البشرية

- النص الإنجليزي المعتمد سريرياً هو source text للإصدار الأول؛ لا تبدأ الترجمة من مسودة متحركة.
- يترجم مترجم طبي عربي، ثم يراجع ممرض ثنائي اللغة لم يكتب الترجمة.
- تستخدم ترجمة معنى لا ترجمة حرفية، مع الحفاظ على درجة اليقين والسرعة والخطر والنفي والاستثناء.
- يحتفظ بقاموس مصطلحات معتمد للأقسام، ABCDE، التصعيد، التسليم، الوعي، الإرواء، الإنتان، والوحدات.
- لا تُعرّب الأرقام أو الاختصارات عندما يسبب ذلك لبساً؛ توضح عند أول ظهور، وتحافظ على ترتيب الجرعة والوحدة.
- تراجع عناصر RTL بصرياً؛ لا تعكس ECG أو المخططات أو ترتيب الزمن أو وحدات القياس لمجرد عكس الواجهة.
- يمنع نشر ترجمة آلية فقط. يجوز استخدام أداة للمسودة إذا سمحت الخصوصية والترخيص، لكن يلزم تحرير بشري ومراجعة مستقلة موثقة.
- أي تعديل سريري في الإنجليزية يعيد النسخة العربية إلى `translation-review`؛ لا يسمح بتباعد الإصدارات بصمت.
- يجرى اختبار فهم مع متعلمين ناطقين بالعربية، وتراجع الفروق غير المفسرة في أداء البند بين اللغتين.

## 8. الدرجات وسلامة الأسئلة

- الدرجات تكوينية ولا تمثل competence أو licence أو credential.
- لكل خيار rationale مستقل يشرح سبب الأمان أو النقص أو التأخير أو عدم الأمان من دون إذلال المتعلم.
- لا تستخدم distractors سخيفة؛ يجب أن تكون محتملة تعليمياً لكن غير ملتبسة بعد تطبيق المعلومات المتاحة.
- لا تجعل موضع الإجابة أو طولها أو نبرتها مفتاحاً للتخمين. يوازن المحرر أطوال الخيارات، ويختبر توزيع الموضع عبر المكتبة. إذا خلطت الواجهة الخيارات فيكون الخلط ثابتاً داخل المحاولة ولا يتغير عند إعادة العرض أو تبديل اللغة، مع حفظ معرف الخيار لا ترتيبه.
- يراجع المقرر ما إذا كان الخيار يعتمد على بروتوكول محلي أو توفر مورد؛ عندها يذكر الشرط صراحة.
- أي خيار `unsafe` يجب أن يولد إشارة سلامة ظاهرة ولا يحمل درجة مرتفعة.
- تستخدم التحليلات سبعة مجالات مشتركة: التقييم والتعرّف على المخاطر، الأولويات والاستجابة، التصعيد والتنسيق، إعادة التقييم والمراقبة، التواصل والتسليم، السلامة والجودة، والرعاية المتمحورة حول الشخص. تبقى وسوم المهارات التفصيلية لأغراض الشرح والتغطية.
- لا تدخل المحاولة الجزئية في تحليل المجالات، ويظهر نطاقها `incomplete`. تتطلب تسمية مجال ضعف، في نموذج الـMVP، ثلاثة قرارات من محاولات مكتملة على الأقل عبر سيناريوهين؛ وما قبلها «بيانات غير كافية».
- لا يغير فريق المنتج الحدود أو الدرجات بعد نشرها دون إصدار جديد، مبرر، وموافقة سريرية.
- قبل استخدام النتيجة في تقييم عالي المخاطر يلزم دراسة صلاحية وموثوقية وعدالة منفصلة، وإشراف جهة تعليمية مخولة. الـMVP غير مخصص لذلك.
- لا يحسب بنك الأسئلة درجة لمجموعة متروكة يدوياً. إذا انتهى العداد، تسجل المجموعة كمنتهية بالوقت وتحتسب الأسئلة غير المجابة كإجابات غير صحيحة. لا تظهر إشارة فئة قبل ثلاثة أسئلة فريدة عبر مجموعتين مكتملتين، ولا يجوز أن يتحول تكرار السؤال أو السيناريو نفسه إلى دليل إضافي.
- ينشئ التدريب الموجّه مجموعة ثابتة قبل البدء، ويفضل غير المجاب، ويحمي تنوع المجالات. لا يغير السؤال التالي وفق الاستجابة الحالية، ولا يسمى CAT، ولا يقدر القدرة أو الجاهزية أو احتمال النجاح.
- تخزن ملخصات السيناريوهات والأسئلة والجلسة المؤقتة النشطة في `localStorage` وتُعاد معايرتها من المحتوى الحالي؛ الموعد النهائي للعداد مطلق حتى لا يضيف تحديث الصفحة وقتاً. هذه البيانات ليست سجلاً تعليمياً موثقاً أو قاعدة لاتخاذ قرار قبول أو توظيف أو اشتراك.

## 9. الإصدارات والمراجعة والسحب

### حالة المحتوى

```text
draft
  → clinical-review
  → evidence-review
  → translation-review
  → qa
  → published
  → superseded أو withdrawn
```

لا يمكن للقفز التقني أو صلاحية المشرف تجاوز أي مراجعة مطلوبة.

### الإصدار

- `MAJOR`: تغير يبدل القرار الأفضل أو تسلسل السلامة أو الجمهور أو نموذج الدرجة.
- `MINOR`: خطوة أو هدف أو تفسير أو مرجع جديد لا يعكس الحكم السابق.
- `PATCH`: لغة أو وصول أو رابط لا يغير المعنى السريري.
- تحفظ النسخة التي أجاب عليها المتعلم في سجل المحاولة الإنتاجي حتى يفهم التقرير تاريخياً؛ لا يعاد احتساب نتائج قديمة بصمت.

### دورية المراجعة

- الإنعاش، الإنتان، الفرز، الدواء، الأطفال والأمومة: فحص إشارات كل 3 أشهر ومراجعة رسمية كل 6 أشهر.
- بقية الحالات: فحص إشارات كل 6 أشهر ومراجعة رسمية سنوية.
- فحص آلي/يدوي للروابط شهرياً، مع التحقق من أن الصفحة ليست مجرد عنوان تغير محتواها.
- المراجعة الفورية عند تحديث إرشاد، تحذير دوائي/سلامة، تغير نطاق ممارسة أو بروتوكول، بلاغ مستخدم موثوق، أو تحليل يظهر غموضاً/تفاوتاً لغوياً.

### السحب العاجل

يسحب الناشر الحالة فوراً من المحاولات الجديدة عند احتمال ضرر، مرجع مسحوب، خطأ جرعة/هوية/تصعيد، تعارض قانوني، أو نسخ غير مرخص. الإجراء:

1. تحويل الحالة إلى `withdrawn` وإيقاف بدء محاولات جديدة؛ يفشل النشر بإغلاق آمن.
2. تسجيل السبب والمبلغ والوقت والنسخ واللغات المتأثرة.
3. إبلاغ رئيس المجلس وقائد المجال والأمن/القانوني بحسب السبب.
4. تقييم أثر المحاولات السابقة والتواصل التعليمي اللازم دون كشف أداء فردي غير ضروري.
5. مراجعة ثنائية مستقلة وتصحيح بإصدار جديد؛ لا تعاد الحالة تلقائياً.
6. نشر ملاحظة تغيير واضحة عندما يفيد المتعلمين، مع حفظ أثر التدقيق.

هدف تشغيلي مقترح: تعطيل فوري عند خطر وشيك، triage خلال 4 ساعات، وقرار إصلاح/استمرار سحب خلال يوم عمل. يعتمد الـSLA النهائي قبل الإنتاج.

## 10. الترخيص والإسناد

- يخزن سجل المصدر: صاحب الحق، رابط الشروط، نوع الترخيص، هل يسمح بالاقتباس/التكييف/الترجمة/الاستخدام التجاري، الإسناد المطلوب، وتاريخ التحقق.
- الرابط العام لا يعني أن النص أو الشكل أو السؤال متاح لإعادة الاستخدام.
- تحتفظ AHA وENA وINACSL وناشرو المجلات بحقوق موادهم؛ لا تعاد الخوارزميات أو أسئلة الدورات أو الرسومات من دون إذن.
- تتحقق شروط WHO لكل عمل على حدة؛ بعض منشوراتها تحمل تراخيص IGO محددة ولا يجوز تعميمها على كل صفحات WHO.
- تتحقق شروط CDC والاستثناءات والعلامات والشعارات قبل إعادة النشر، حتى عندما يسمح القانون بإعادة استخدام نص حكومي معين.
- تطبق شروط NICE وSCCM/ESICM وQSEN/AACN وSCFHS وSPSC ووزارة الصحة والناشر المرتبط.
- تستخدم روابط الناشر/DOI، وعنوان العمل والجهة والسنة، وصياغة تعليمية أصلية. أي شكل أو مقتطف يتجاوز الحد التحريري يحتاج إذناً محفوظاً.
- تراجع الروابط والحقوق أيضاً عند الانتقال من عرض غير تجاري إلى منتج تجاري؛ قد يتغير نطاق الإذن.

## 12. فحص حداثة المراجع

لا تعني عبارة «حتى 2026-09-04» أن المصدر سيبقى الأحدث. قبل نشر أو إعادة نشر حالة:

1. افتح صفحة الجهة، لا نسخة مخبأة أو رابطاً ثانوياً.
2. سجل رقم الإصدار وتاريخ النشر والتحديث أو التصحيح.
3. افحص erratum، correction، retraction، focused update، والتنبيه التنظيمي.
4. قارن بالمصدر المحلي السعودي والبروتوكول المؤسسي المستهدف.
5. حدّث `lastEvidenceCheckAt` حتى لو لم تتغير التوصية.
6. إذا تعذر الوصول للنص اللازم، لا تستنتج من العنوان أو الملخص؛ ضع الحالة `evidence-review` أو أوقفها.

## 13. الخصوصية والأمن في المحتوى

- تمنع نماذج التأليف أسماء المرضى وأرقام الملفات والتواريخ الدقيقة والصور والمواقع النادرة والخصائص المركبة القابلة لإعادة التعرف.
- لا تحفظ بلاغات المحتوى بيانات مريض؛ يوفر النموذج تنبيهاً وحذفاً تلقائياً للحقول غير اللازمة، مع قناة آمنة إن احتاج التحقيق المؤسسي.
- لا تسجل كلمات مرور أو رموز أو بيانات حساسة أو نصوص حالة أرسلها مستخدم إلى أدوات التحليل.
- يعرض الـMVP حالات مؤلفة ثابتة فقط؛ لا دخول تجريبي، ولا seed لمسجلات أشخاص، ولا اعتراض لطلبات المتصفح.
- يحفظ المتصفح الحد الأدنى من معرفات محاولات السيناريو والأسئلة والنتائج المعاد احتسابها فقط؛ لا توجد مصادقة أو قاعدة بيانات أو مزامنة أو استعادة أو مدفوعات حقيقية.
- أي بحث أو AI أو بريد أو تحليلات مستقبلية معطلة افتراضياً وتفشل بإغلاق آمن حتى اعتماد تدفق البيانات والعقد والمنطقة والاحتفاظ والأسرار ودليل التشغيل.
- n8n، إذا اعتمد مستقبلاً، يبقى طبقة أتمتة وتكامل خلفية وليس واجهة الموقع أو مخزن المحتوى أو نظام الاستحقاق. لا يرسل إليه المتصفح أحداث صلاحية، ولا يمنح فشل workflow وصولاً أو ينشر محتوى. تطبق الحدود التشغيلية في [N8N_INTEGRATION.md](N8N_INTEGRATION.md).

## 15. بوابات العرض مقابل الإنتاج

### Showcase blockers

- أي حالة بلا تحذير، تفسير ثنائي اللغة، مصدر رسمي، أو تأكيد خيال.
- أي سؤال بلا مبرر خاص بكل خيار ومصدر سريري مباشر عند الحاجة، أو يحمل ادعاءً رسمياً/تنبؤياً، أو يفتقد حالة المسودة وسجل المنشأ.
- رابط أساسي معطل أو إصدار مذكور لا يطابق صفحة الجهة.
- ترجمة تغير درجة اليقين أو الفئة أو الإجراء.
- قرار `unsafe` بدرجة عالية أو إجابتان مقبولتان من المعلومات المعروضة.
- نمط موضع/طول متكرر يكشف الإجابة الصحيحة دون تطبيق الهدف التعليمي.
- وجود نص منسوخ أو حق إعادة استخدام غير محسوم في مادة ظاهرة.
- إدخال/عرض بيانات مريض، دخول تجريبي، بيانات أشخاص مزروعة، أو طلب خارجي غير معتمد.
- فشل اختبارات المشروع أو رحلة العربية/الإنجليزية عند `390px` ولوحة المفاتيح.
- مسار `#/questions` أو `#/membership` مكسور، أو ظهور سعر/شراء/اشتراك فعلي، أو غياب التذييل `Abdulkarim alhejaili`.

### Production blockers

- مجلس غير معين فعلياً، نصاب أو سجل قرار غير مطبق، أو عدم وجود ناشر مسؤول.
- غياب نظام إصدار ومراجعة إشارات وسحب قابل للتنفيذ والتدقيق.
- حقوق الترجمة/التكييف/الاستخدام التجاري غير محسومة.
- غياب دراسة صلاحية وعدالة إذا ستؤثر الدرجات في برنامج أو شخص.
- غياب الهوية والتفويض والاحتفاظ والحذف والخصوصية والأمن والمراقبة ودليل الحوادث.
- غياب استحقاقات خادمية ومدفوعات موثقة ومختبرة إذا فُعّلت العضويات؛ لا تعتمد الصلاحية على الواجهة أو `localStorage` أو n8n.
- تكامل خارجي بلا عقد وDPA وتقييم منطقة واحتفاظ وفشل ودليل تشغيل.
- ادعاء اعتماد أو شهادة أو ساعات تعليم مستمر دون موافقة الجهة المخولة.

نجاح الاختبارات والبناء يثبت سلامة تقنية محدودة للنسخة المفحوصة فقط؛ لا يثبت صحة سريرية أو اعتماداً أو جاهزية إنتاجية.

## 16. قائمة قرار النشر

لا يتحول السيناريو إلى `published` قبل وجود إجابة «نعم» موثقة لكل بند:

- [ ] خيالي بالكامل ولا يحتوي بيانات مريض أو خصائص قابلة لإعادة التعرف.
- [ ] أهداف وجمهور ونطاق ممارسة واضح.
- [ ] إن كان المحتوى سؤال تدريب، فهو أصلي ويحمل `official: false` و`claims.predictive: false` ويرتبط بمصدر سريري مناسب من دون إعادة استخدام بند اختبار أو مادة سرية.
- [ ] كل قرار وتفسير متتبع إلى مصدر حالي ومناسب.
- [ ] قوة التوصية واليقين والقيود محفوظة بدقة.
- [ ] كتابة أصلية وفحص تشابه وترخيص مكتمل.
- [ ] قائد المجال ومراجع مستقل وأخصائي المحاكاة وافقوا.
- [ ] الصيدلي/العدوى/مختص الفئة وافق عند الحاجة.
- [ ] ترجمة بشرية ومراجعة تمريضية ثنائية اللغة مستقلة.
- [ ] الدرجات والتصنيفات متسقة ولا تخفي خطراً.
- [ ] التحذير ظاهر والمراجع تفتح.
- [ ] تنبيه عدم الارتباط الرسمي ظاهر، ولا يوجد ادعاء تنبؤ بالترخيص أو اعتماد أو CAT.
- [ ] اختبارات وظيفية ووصول بالعربية والإنجليزية و`390px` موثقة.
- [ ] إصدار وتاريخ نشر ومراجعة تالية ومالك وسجل تغييرات موجودة.
- [ ] تمرين السحب أو آليته متاح للمشغل قبل الإنتاج.
